# 01：清單屬於功能

**What to build:** 每份 Waypoint List 建立時就屬於美片菇、無人巨菇或指定菇菇其中一個，只在那個功能分頁出現、只能跑那個功能。「座標清單」分頁拿掉，三個功能分頁各自有清單管理，並各自記住目前選的清單（這張先存在記憶體，重新整理不保留）。對應 spec user story 1–4、9、12（清單部分）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 建立清單必須帶功能；缺少或不合法時後端回 400。建立後不能改功能
- [ ] 列清單時依功能過濾，只回該功能的清單；不帶功能回 400
- [ ] 美片菇、無人巨菇、指定菇菇分頁用到清單時，後端都會檢查清單的功能，不符就回 400
- [ ] 分頁變成：無人巨菇、探索區域、美片菇、指定菇菇、歷史；「座標清單」分頁不存在
- [ ] 三個功能分頁各有共用的清單管理元件：下拉選清單、建立、改名、刪除、匯入、Waypoint 列表（上移、下移、編輯、刪除沿用現有行為）
- [ ] 各分頁選的清單互不影響；切分頁後回來，仍是原本選的清單
- [ ] 地圖只畫目前功能分頁選定清單的 Waypoint；探索區域和歷史分頁不畫任何清單
- [ ] 後端測試涵蓋：功能必填、依功能過濾、用錯功能的清單開 Batch 被拒
