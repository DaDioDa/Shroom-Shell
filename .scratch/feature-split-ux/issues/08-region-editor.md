# 08：Region 編輯器（格子對齊）

**What to build:** 照 prototype 選定的 C 版本做 Region 編輯器，取代拖曳畫框：
- 8 個把手，寬高對齊間距的整數倍，拖本體可以平移
- 超過 10 km 時框變紅、不能開始
- 即時畫出格子預覽、蛇形路線，以及欄 × 列統計和覆蓋提示

對應 spec user story 24、25、29–40、53（Region 部分）。

參考：throwaway 分支 `proto/region-editor` 的 `web/src/prototype/RegionEditorPrototype.tsx`（VariantC）。可以參考寫法，但要重寫，不要直接搬過來。

**Blocked by:** 06、07

**Status:** ready-for-agent

- [ ] shared 純函式：
  - 依中心與邊長產生 Region
  - 對齊整數格：`max(1, round(邊長 / 間距)) × 間距`
  - 拖角：對角固定、兩個方向都對齊
  - 拖邊：對邊固定、只改一個方向
  - 平移：寬高不變
  - 都不允許翻面
  - 改間距時以中心為準重新對齊
- [ ] shared 的格子統計：
  - 欄數、列數、點數、實際格子尺寸
  - 覆蓋提示：格邊長 > 2R 顯示「有空隙」，否則顯示「無縫，重疊約 X%」
- [ ] 「放一個 Region」在地圖中央放一個約 2 km × 2 km 並對齊的框；之後顯示「移到地圖中央」
- [ ] 8 個把手（四角加四邊中點）與矩形本體都可以拖；拖曳中把手不重建
- [ ] 矩形上方即時顯示寬高；超過 10 km 時框和標籤變紅，面板顯示原因，「開始」不能按，但仍然可以繼續拖
- [ ] 格子預覽用 canvas 畫：淡色的 2R 正方形、格子點、蛇形路線（橘線）、「起點」標記
- [ ] 面板醒目顯示「欄 × 列 格 = N 點」、預估時間、覆蓋提示
- [ ] 間距用 Slider；「跟半徑連動」預設勾起，勾著時間距 = 2 × 半徑，可以超過手動上限 3000
- [ ] 超過 30 點時在面板內確認，不跳瀏覽器對話框
- [ ] Discovery 排隊或執行中時，把手隱藏、不能拖
- [ ] localStorage 記住 Region、間距、連動勾選
- [ ] 拿掉舊的拖曳畫矩形模式
- [ ] shared 測試涵蓋上述幾何與統計
