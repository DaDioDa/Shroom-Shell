# 09: run 資料夾 1 GB 上限

**What to build:** 本專案的 run 資料夾總量超過 1 GB（可設定）時，從最舊的 Batch 開始刪除它的 run 資料夾，直到總量低於上限。SQLite 裡的文字結果保留，例如種類、人數、座標、判斷結果。歷史頁與結果卡片上，原本放截圖的地方改顯示「圖片已清除」。

清理時機：每個 Batch 結束後檢查一次，App 啟動時也檢查一次。正在執行的 Batch 不會被清掉。

**Blocked by:** 08（Sighting 到期規則與歷史頁）

**Status:** ready-for-agent

- [ ] 超過上限時，從最舊的 Batch 開始刪，直到低於上限。
- [ ] 正在執行的 Batch 不會被刪。
- [ ] 被清掉圖片的 Batch 文字結果還在，UI 顯示「圖片已清除」。
- [ ] 上限可以在設定調整。
- [ ] 刪除順序與停止條件有自動化測試（用暫存資料夾與小上限）。
